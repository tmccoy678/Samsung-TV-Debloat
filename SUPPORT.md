# Support

Start with `./install --check` and the troubleshooting guidance printed by the
installer. Search existing issues before opening a new one.

For a useful support request, include the repository commit, television model,
firmware identifier, host operating system, the installer stage that stopped,
and sanitized command output. State whether the result came from a dry run,
automated test, or observation of the physical screen.

Remove LAN addresses, Samsung account details, remote-control tokens, serial
numbers, database contents, and backup paths before posting. Hardware outside
`docs/COMPATIBILITY.md` is a request for research rather than an installation
failure.
